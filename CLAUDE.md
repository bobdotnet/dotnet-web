# Dotnet.ie Website

This repository contains the Dotnet.ie website.

Primary objective:

Position Dotnet.ie as the leading modernisation platform for distributors,
wholesalers and growing businesses.

Flagship product:

GenetiQ ERP

Supporting products:

- Gabby Intellidoc
- IndigoPro
- Intelligence Advantage
- Microsoft 365
- Copilot
- Managed Security

Design Language:

- Vercel
- Linear
- Apple
- Stripe

The site should never look like a traditional MSP website.

GenetiQ is the hero product and should receive the majority
of homepage attention.

The visual hierarchy should be:

1. GenetiQ
2. AI Automation (Gabby / IndigoPro)
3. Microsoft 365 & Copilot
4. Intelligence Advantage
5. Managed Services

Target audience:

- Builders Merchants
- Electrical Wholesalers
- Plumbing Wholesalers
- Distribution Companies
- SMEs with 20-500 users

Technology:

- Next.js 15
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
